## 📌 Parte 3 — Estratégias de Leitura

> _"Toda leitura deve ter um objetivo. Lemos porque queremos algo da leitura."_ — Souza et al (2005)

### 🔍 As 3 Estratégias Fundamentais

```
┌─────────────────────────────────────────────────────────┐
│  SKIMMING → SCANNING → LEITURA DETALHADA               │
└─────────────────────────────────────────────────────────┘
```

| Estratégia            | O que é                             | Como usar                                         |
| --------------------- | ----------------------------------- | ------------------------------------------------- |
| **Skimming**          | Leitura rápida para **ideia geral** | Olhar títulos, subtítulos, imagens, cognatos      |
| **Scanning**          | Busca de **informação específica**  | Varrer o texto em busca de um dado concreto       |
| **Leitura Detalhada** | Compreensão **completa** do texto   | Ler com atenção, comparar com conhecimento prévio |

> 🎯 **Dica para você, Alex:** No TryHackMe e manuais Cisco/Fortinet, use **Skimming** primeiro para ter o contexto geral, depois **Scanning** para achar comandos e configurações específicas!

## 📌 Parte 4 — Texto: World Englishes

### O que são "World Englishes"?

> Termo que se refere às **diferenças na língua inglesa** que emergem conforme ela é usada em **variados contextos ao redor do mundo**.

### 💡 Conceito-chave: Adaptação

- As línguas se desenvolvem para **atender às necessidades das sociedades**
- Uma nova variedade surge por um **processo de adaptação**

### 📝 Exemplo prático do texto

|Situação|American English 🇺🇸|British English 🇬🇧|
|---|---|---|
|Loja de bebidas alcoólicas|**Liquor store**|**Off-licence**|

### ✅ Variações acontecem em:

- Escolha de palavras
- Ortografia _(spelling)_
- Pronúncia
- Estrutura de frases _(sentence structure)_
- Sotaque _(accent)_
- Significado _(meaning)_

## 📌 Parte 5 — Cognatos e Falsos Cognatos

### ✅ O que são Cognatos?

> Palavras de **origem grega ou latina** com grafia, significado e pronúncia **similar** em inglês e português.

| Inglês    | Português |
| --------- | --------- |
| Comedy    | Comédia   |
| Different | Diferente |
| Emotion   | Emoção    |
| Future    | Futuro    |
| Human     | Humano    |

---

### ⚠️ False Friends — Falsos Cognatos

> Palavras com **grafias similares** mas **significados DIFERENTES**!

|Palavra em inglês|Parece ser…|Mas significa…|
|---|---|---|
|**Actual**|Atual|**Verdadeiro**|
|**Anthem**|Antena|**Hino**|
|**Application**|Aplicação|**Inscrição**|
|**Fabric**|Fábrica|**Tecido**|
|**Lecture**|Leitura|**Palestra**|
|**Parents**|Parentes|**Pais**|
|**Pretend**|Pretender|**Fingir**|
|**Shoot**|Chute|**Atirar / Fotografar**|
|**Push**|Puxar|**Empurrar**|
|**Exit**|Êxito|**Saída**|


> ⚠️ **Atenção especial, Alex:** Em manuais técnicos, **"Fabric"** aparece muito em redes (ex: _network fabric_, _SD-WAN fabric_) e significa **infraestrutura/malha**, não fábrica! Cuidado com esse false friend no contexto de segurança!

## 📌 Parte 6 — World Englishes: Variedades Híbridas

### 🗣️ Variações do Inglês ao redor do mundo

| Código | Nome                | Descrição                                                                |
| ------ | ------------------- | ------------------------------------------------------------------------ |
| **A**  | **Spanglish**       | Inglês com forte influência do espanhol — comunidades hispânicas nos EUA |
| **B**  | **Frenglish**       | Inglês misturado com francês (= Franglais)                               |
| **C**  | **Black English**   | Dialetos do inglês americano falados pela comunidade negra nos EUA       |
| **D**  | **Hinglish**        | Inglês com elementos do Hindi                                            |
| **E**  | **Singlish**        | Inglês de Singapura — com elementos do chinês e malaio                   |
| **F**  | **Wenglish**        | Dialeto inglês do País de Gales _(Wales)_                                |
| **G**  | **Chinglish**       | Inglês influenciado pela gramática e vocabulário chinês                  |
| **H**  | **Nigerian Pidgin** | Língua crioula baseada no inglês — língua franca real da Nigéria         |

### ✅ Gabarito da Atividade

```
(E) Singlish → Singapore
(F) Wenglish → Welsh / Wales
(D) Hinglish → Hindi
(A) Spanglish → Spanish / US Hispanic
(C) Black English → African American English
(G) Chinglish → Chinese
(B) Frenglish → French
(H) Nigerian Pidgin → Nigeria
```
